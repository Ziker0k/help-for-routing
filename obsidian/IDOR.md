## Определение
IDOR (Insecure Direct Object References) "Небезопасная прямая ссылка на объект" - уязвимость, при которой пользователь может получить доступ к объекту, к которому доступ должен быть запрещен.

## Защита от IDOR
- Создание случайных идентификаторов. 
  Например, использование вместо ID идентификационные хеши. Таким образом получить доступ к другим объектам(чужим) будет крайне сложно.
- Следует использовать различные методы идентификации, например JWT-токены.
  В таком случае на сервере могла бы быть проверка на то, действительно ли принадлежит токен с определенным ID пользователю, который обращается по ссылке. Если не принадлежит, то доступа нет.
- Должна присутствовать фильтрация ввода пользователей.
