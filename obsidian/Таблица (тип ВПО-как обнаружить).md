| **Вид ВПО (RU/EN)**                               | **Как видно через СЗИ (AV/EDR/SIEM/NDR)**                                                                                                                 | **Как проверить вручную (без СЗИ)**                                                                                                                         |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Разрушающее / Destructive (Ransomware, Wiper)** | - Алерты AV/EDR на массовое шифрование файлов- Срабатывания SIEM на резкий рост ошибок доступа к файлам- Аномалии в логах (массовое изменение расширений) | - Внезапное изменение расширений файлов- Увеличение зашифрованных/битых документов- Подозрительные процессы с высокой активностью диска                     |
| **Шпионское / Spyware**                           | - EDR фиксирует кейлоггеры и скрытые процессы- DLP срабатывает на утечку данных- SIEM показывает аномальные исходящие соединения                          | - Проверка автозагрузки (autoruns, msconfig)- netstat → неизвестные исходящие соединения- Наличие скрытых процессов, которые читают клавиатуру/буфер обмена |
| **Финансовое / Financial malware**                | - Срабатывания AV/EDR по сигнатурам банковских троянов- SIEM фиксирует странные POST-запросы- NDR: трафик к C2-серверам                                   | - Подозрительные процессы в браузере- Перехват форм (подмена страниц)- Логи веб-трафика → неизвестные домены/серверы                                        |
| **Рекламное / Adware**                            | - AV фиксирует потенциально нежелательное ПО (PUA/PUP)- SIEM: массовые HTTP-запросы на рекламные сети                                                     | - Постоянные всплывающие окна, редиректы- Новые расширения в браузере- Подозрительные задачи в планировщике                                                 |
| **Криптомайнеры / Cryptojackers**                 | - EDR/NDR фиксируют высокую загрузку CPU/GPU- SIEM: постоянный трафик на пулы майнинга- AV: срабатывания на XMRig и аналоги                               | - Постоянная 90–100% загрузка процессора/видеокарты- Перегрев устройства- Неизвестные процессы (taskmgr, top, htop)                                         |
| **Черви и боты / Worms & Botnets**                | - IDS/IPS срабатывает на массовые сканы и распространение по SMB/RDP- SIEM показывает множественные неудачные входы- NDR фиксирует DDoS-активность        | - Всплеск сетевого трафика- Массовые попытки подключений на соседние машины- Необычные сервисы слушают порты                                                |
| **Rootkit / Bootkit**                             | - EDR фиксирует попытки работы на уровне ядра- SIEM: события о скрытии драйверов- AV: сигнатуры rootkit                                                   | - Несовпадение хэшей системных файлов с эталоном- Подозрительные драйверы в системе- Разные результаты при запуске dir и низкоуровневых инструментов        |
| **ICS/SCADA malware**                             | - SIEM/NDR: аномалии в трафике на PLC/SCADA- IDS срабатывает на нестандартные команды- Срабатывание специализированных средств OT-безопасности            | - Необычные команды к контроллерам- Некорректная работа оборудования- Сбои и перезагрузки ПЛК                                                               |
