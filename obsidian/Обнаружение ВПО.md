### Если есть СЗИ
1. Антивирус / [[EDR]] / [[XDR]]
	- Антивирусные агенты + поведенческие анализаторы.
	- [[EDR]] (Endpoint Detection & Response) фиксирует подозрительные процессы, сетевые соединения, загрузку CPU/GPU.
	- [[XDR]] (Extended Detection & Response) агрегирует данные с сетевых устройств, хостов, почтовых шлюзов.
2. [[SIEM]] (Security Information and Event Management)
	- Корреляция логов: входы в систему, аномалии в трафике, нестандартные процессы.
	- Обнаружение [[IOC]] (Indicators of Compromise).
3. [[IDS]]/[[IPS]] (Intrusion Detection/Prevention Systems)
4. [[NTA]]/[[NDR]] (Network Traffic/Detection & Response)
5. [[DLP]] (Data Loss Prevention)
6. [[Sandbox]]

### Если СЗИ нет

1.  Файловая система и процессы
	- Проверка автозагрузки (msconfig, taskmgr, autoruns в Windows).
	- Сравнение хешей системных файлов с эталонами (например, sfc /scannow, sigcheck).
	- Подозрительные процессы (неизвестные .exe, высокая загрузка CPU/GPU). 
2. Сеть
	- netstat -ano (Windows) или ss -tulpn (Linux) – поиск неизвестных соединений.
    - Мониторинг DNS-запросов (частые обращения к неизвестным доменам).
    - Анализ прокси- и веб-логов (необычные URL, POST-запросы).
3. Ресурсы системы
	•	Внезапно высокая загрузка процессора/видеокарты → майнер.
	•	Резкое падение производительности, перегрев → признак криптоджекинга.
4. Журналы
	•	Windows Event Log, Linux journalctl.
	•	Аномальные события: новые пользователи, отключение антивируса, ошибки безопасности.
5. Ручной анализ подозрительных файлов
	•	Проверка хэшей через VirusTotal.
	•	Запуск в изолированной VM.
	•	Анализ строк (strings, bintext) для поиска подозрительных доменов, API, ключевых слов.
6. [[IOC]] / [[YARA]]
	•	Использование индикаторов компрометации (списки хэшей, IP, доменов).
	•	Написание простых YARA-правил для поиска сигнатур в файлах.
