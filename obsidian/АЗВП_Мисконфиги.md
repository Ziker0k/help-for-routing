# Практика
### 1. lesson misconfiguration
==localhost/lesson1/misconfiguration/tinyfilemanager.php==
Имеем tinyfilemanager с базовыми настройками. Учетные данные не переопределены.

Заходим со стандартными учетными данными:
login: admin
password: admin@123

Можем загрузить вредоносный PHP-файл, который обеспечит реверс-шелл(удаленный доступ от лица веб-сервера). Готовый файл можно взять из Github.
https://github.com/pentestmonkey/php-reverse-shell

Для удобства копируем Raw

Переходим в директорию /opt/
У обычного пользователя нет прав для записи файлов в данную директорию. Необходимо повысить права.

Используем `sudo wget "ссылка на файл в формате raw"`.

Теперь нужно запустить listener на терминале, в котором будем ловить reverse-shell.
nc -nvlp 1234

-l используется чтобы сообщить netcat, что это будет прослушиватель.
-v используется для запроса подробного вывода.
-n указывает netcat не разрешать имена хостов и не использовать DNS.
-p указывает, что последует спецификация порта.

Загружаем через интерфейс reverse-shell на сервер и запускаем. Получаем доступ к командной строке сервера от имени веб-сервиса.

### 2. misconfiguration linux
На виртуальной машине также есть misconfiguration
Есть пользователь misconfiguration с простейшим паролем `123`

Используем команду `su - misconfiguration`
%% Команда su в Linux используется для переключения пользователя в командной оболочке на другого пользователя, по умолчанию на суперпользователя root. При вводе su система запрашивает пароль пользователя, на которого происходит переключение.
После успешной аутентификации текущий пользователь временно получает права другого пользователя.

Команда с - дополнительно подгружает окружение пользователя, включая переменные среды и домашний каталог, что имитирует полноценный вход в систему под этим пользователем. Это полезно для выполнения команд с правами другого пользователя, особенно администратора, без выхода из текущей сессии и перезагрузки системы. %%

Далее используем `sudo -l`
%% Команда используется для отображения списка команд, которые текущий пользователь имеет право выполнить через sudo. Эта команда позволяет узнать, какие именно права делегированы пользователю в файле конфигурации sudoers. 
Это удобно для проверки своих прав перед выполнением команд с sudo и для администраторов, для управления доступом пользователей. %%
